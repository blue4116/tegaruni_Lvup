# 軽作業レベルアップアプリ

GitHub Pagesで公開できる、ブラウザだけで動く初版です。

## ファイル
- index.html
- style.css
- script.js

## 主な機能
- 総合レベル・EXP
- ソフト選択
- ソフトごとのレベル・EXP
- 作業記録
- 作業時間
- 難易度によるEXP計算
- 成長記録
- localStorageによる自動保存
- スマホ対応
- ソフトの追加

## GitHub Pages
GitHubリポジトリに3ファイルをアップロードし、
Settings → Pages → Deploy from a branch → main → / (root)
を選択して公開できます。
